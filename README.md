## 현재 상태

- 프로젝트명: KT skylife 가입신청 랜딩페이지
- 저장소: `k2500rjin-alt/skylife_form_v2`
- 주요 파일: `index.html`
- 배포 방식: GitHub Pages
- 배포 상태: 배포 완료
- 배포 기록일: 2026-07-29 새벽

## 주요 기능

- 인터넷 가입 상담 CTA
- 전화 상담 예약 / 직접 가입 신청 선택
- 이름, 연락처, 설치 희망 주소, 상담 희망 시간 입력
- 대표번호 `1668-0096` 연결
- Google Apps Script 엔드포인트로 상담 신청 정보 전송
- 모바일 대응형 단일 HTML 랜딩페이지
